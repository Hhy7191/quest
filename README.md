# 설문 설계 스튜디오

연구문제 → 변인·조작적 정의 → 선행연구·도구 검토 → 문항 구성 → 평가·분석 → 점검 → 설문지·설계표

## GitHub Pages 게시

1. ZIP 압축을 풉니다.
2. GitHub 저장소에서 Add file → Upload files를 선택합니다.
3. **이 폴더 자체가 아니라 내부의 index.html, fonts 폴더, README.md 등의 파일을 저장소 최상위에 업로드**하고 Commit changes 합니다.
4. Settings → Pages → Build and deployment에서 Source를 Deploy from a branch로 선택합니다.
5. Branch에서 main과 /(root)를 선택하고 Save 합니다.
6. 배포가 끝나면 Pages에 표시된 사이트 주소를 엽니다.

저장소 최상위에 index.html이 있어야 합니다. ZIP 파일만 올리거나 상위 폴더째 올리면 앱 첫 화면이 열리지 않습니다. main 대신 다른 기본 브랜치를 사용한다면 그 브랜치를 선택하세요.

## 기능

- 변인·내용 요소·조작적 정의와 문항의 연결
- 원문·척도·신뢰도·타당도·수정 및 허가 근거 기록
- 교육용 예시, 누락 점검, 설문 미리보기
- JSON 저장·불러오기, CSV·HTML 내려받기, 인쇄
- 브라우저 자동 저장, 반응형 화면, Pretendard 글꼴

## 데이터와 접근

서버나 설치 없이 작동하는 정적 웹앱입니다. 작성 내용은 해당 기기·브라우저의 사이트 저장소에 남으며 다른 사용자와 동기화되지 않습니다. 중요한 설계는 JSON으로 내려받으세요. 다른 주소로 이동하면 이전 주소의 자동 저장 내용은 표시되지 않으므로 원래 앱에서 설계 저장 후 새 앱에서 불러오기 하세요.

응답 미리보기는 제출·응답 수집 기능이 아닙니다. 기존 논문 자동 검색이나 통계 분석 기능도 포함하지 않습니다. 예시는 검증된 표준 척도가 아닙니다.

GitHub Pages는 일반적으로 인터넷 공개 사이트이므로 사이트 주소를 아는 사람이 접근할 수 있습니다. 현재 ChatGPT에서 제공하는 비공개 사이트와는 별도입니다. 연구자료나 개인정보를 HTML 소스에 넣지 마세요.
